# AI Text Summarizer

## About

A Python-based application that converts long paragraphs into short and meaningful summaries.

## Features

* Enter long text.
* Generate short summaries.
* Extract important information.
* Display summarized content.

## Technologies

* Python
* NLP
* Hugging Face Transformers
* Streamlit

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
